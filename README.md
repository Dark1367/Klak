# KLAK: магазин механических клавиатур

Многостраничный сайт интернет-магазина механических клавиатур, свитчей, кейкапов и аксессуаров.
Есть каталог с фильтрами, сравнение товаров, избранное, корзина и конструктор клавиатуры с расчётом цены.

Сайт написан на чистых **HTML, CSS и JavaScript**, без CSS-фреймворков и сборщиков.

- Опубликованная версия: `https://<логин>.github.io/klak-shop/` *(заменить после включения GitHub Pages)*

## Как запустить

1. Клонировать репозиторий.
2. Открыть `index.html` в браузере или запустить Live Server в VS Code.
3. Для публикации: Settings → Pages → Branch `main`, папка `/ (root)`.

## Возможности сайта

1. **Сравнение товаров.** Кнопка ⇄ на карточке, до 3 товаров одной категории. Таблица в модальном окне, самая низкая цена и самый лёгкий вариант подсвечены, есть переключатель «Показать только различия».
2. **Избранное.** Сердечко на карточках и на странице товара, счётчик в шапке, кнопка «Только избранное» в каталоге. Хранится в `localStorage`.
3. **Конструктор с расчётом цены и живым превью.** 3D-модель сразу меняет формат (65/75/TKL/Full), корпус, цвет кейкапов, а без кейкапов показывает свитчи нужного цвета. Цена считается сразу: стоимость свитчей зависит от количества клавиш в формате, полноразмерный корпус выпускается только проводным. Готовая сборка попадает в корзину со всеми опциями.
4. **Поиск по каталогу.** Работает при вводе, ищет по названию, описанию и характеристикам, «е» и «ё» считаются одной буквой. Если ничего не найдено, показывается заглушка с кнопкой сброса.
5. **Sticky-панель каталога.** Поиск, избранное и сравнение прилипают к верху при прокрутке, в этот момент у панели появляется тень.
6. **Корзина.** Боковая панель на всех страницах: количество, удаление, итог. Одинаковые позиции складываются.
7. **Оформление заказа.** Для каждого способа получения показываются свои поля: у курьера дата и адрес, у пункта выдачи только адрес пункта (дату назначает служба доставки), у самовывоза выбор шоурума. По каждому шоуруму видно, какие товары из корзины есть в наличии, когда заказ будет готов и до какого числа держим бронь. Поля скрытых блоков отключаются и не проверяются.
8. **Первый экран.** Живая 3D-клавиатура Graphite 75 (75%, алюминиевый корпус, энкодер) собрана из HTML-элементов. Вся модель представляет собой одну наклонённую плоскость, объём клавиш нарисован многослойным `box-shadow`, поэтому анимация идёт плавно (около 60 FPS). Заголовок печатается сам, и каждая буква нажимает свою клавишу. Анимация останавливается, когда экран не виден, и отключается при `prefers-reduced-motion`.
9. **Кнопка «Наверх».** Оформлена как клавиша ↑ (кейкап с юбкой и вогнутым верхом), при наведении приподнимается, при клике проседает.
10. **Отзывы.** На странице «О нас»: сводка оценок, карточки отзывов и форма с выбором звёзд; новый отзыв сохраняется в `localStorage` и появляется в списке.
11. **Подвал.** Три колонки: о магазине, навигация по центру (без пункта «Контакты»), контакты с иконками и кнопкой конструктора.

## Как проверить

- Каталог: ввести в поиск `linear` (2 товара), `кейкапы pbt` (3 товара), `qqqq` (заглушка «Ничего не нашлось»).
- Фильтры: «Клавиатуры» + «Беспроводные» → 2 товара; «Сначала дешевле» → первым идёт KLAK 65 Air.
- Сравнение: добавить три клавиатуры, четвёртая кнопка станет неактивной. Если добавить свитч, появится предупреждение про одну категорию.
- Конструктор по умолчанию: 75%, пластик, проводное, Lime Linear, «Lime Pop», смазка = 9 900 + 84 × 35 + 4 590 + 1 200 = **18 630 ₽**.
- Конструктор: при выборе Full пункт «Беспроводное» становится недоступен.
- Заказ: отправить пустую форму, под полями появятся ошибки. После правильного заполнения появится «Форма успешно отправлена!», корзина очистится.
- Сбросить сохранённые данные: DevTools → Application → Local Storage → удалить ключи `klak-cart`, `klak-favorites`, `klak-compare`.
- Адаптивность: DevTools → Toggle device toolbar, ширины 375, 768, 1024, 1440 px.
